A medieval-themed activity discovery website that uses an API to generate random adventures for users.

## Features
- Login system
- Random activity generation using an API
- Displays activity type
- Displays number of participants
- Save favourite adventures
- Medieval/fantasy themed interface
- Background video and music
- Responsive Bootstrap layout

## Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap
- API

## API
Random Activity API: https://random-activity-sigmo.vercel.app/api/random

## How It Works
1. User logs into Muddy City (basically Kuala Lumpur).
2. User enters the dashboard.
3. User clicks "Get Adventure".
4. JavaScript sends a request to the API.
5. The API returns JSON data.
6. JavaScript displays the activity on the webpage.
7. User can save the activity to the Quest Archives.
